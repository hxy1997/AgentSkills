# 财报质量与管理层说法核验

在使用历史数据预测前读取。目标是判断数字能否代表可持续经营，不是预设公司造假，也不是替管理层解释异常。对重大疑点核验附注、会计政策、审计意见及关键审计事项，再与经营和现金证据对照。审计意见正常不等于不存在经营或会计风险。

## 建立可以复核的历史起点

保留“报表原值 → 调整事项 → 正常化值”，每项调整注明期间、税务影响、现金影响、普通股归属、来源和是否会再次发生。不覆盖原始报表。正常化值是研究判断，不是公司披露值。

优先检查足以改变结论的事项，不机械遍历所有账户：

| 线索 | 需要核查 | 对预测的影响 |
| --- | --- | --- |
| 收入快于回款或出货 | 收入确认时点、验收条件、退货、渠道库存、应收账龄、合同资产、关联交易、总额/净额法变化 | 调整销量兑现、回款周期或坏账情景；增长不直接认定虚假 |
| 利润增长快于经营现金流 | 应收、存货、预付款、税费、合同负债变化，季节性及并购范围 | 分开解释利润率和营运资本占用，不能只看现金/利润单年比率 |
| 现金流突然改善 | 应付账期拉长、客户预收、票据/保理及追索权、供应链融资、资产出售或现金分类变化 | 区分持续经营改善与一次性释放；供应商融资可能形成额外索取权 |
| 费用下降或资产增加 | 研发/利息资本化、在建工程转固、折旧年限与残值、费用递延、租赁 | 检查当前利润是否以未来折旧、摊销或现金支出为代价 |
| 利润中包含大额其他项目 | 补助、资产处置、公允价值、投资收益、减值及转回、税率变化 | 区分经常性与非经常性；反复出现的重组费或激励费用不随意加回 |
| 当期利润异常低 | 提前计提、集中减值、保守会计、一次性投入及可验证的回收证据 | 不自动称“藏利润”；已发生资产损失不能因非现金而抹去，未来转回不能先计入 |
| 账上有钱却持续借款 | 受限/质押现金、资金地域、母子公司调拨、债务期限、担保、少数股东权益 | 判断可动用现金、融资缺口与股东能否拿到钱 |

对可疑事项同时列合理经营解释与不利解释，寻找区分两者的证据。异常指标只是核验线索，不能单独证明舞弊或故意“藏拙”。不同会计处理也可能合理，必须说明经济影响。

## 管理层沟通属于待验证证据

检索研究截止日前最近相关的业绩说明会、投资者关系活动记录、官方电话会/文字稿及交易所问询回复；涉及关键变化时回看以前同口径承诺。A 股没有电话会时使用官方说明会记录，不要求虚构电话会。

- 记录会议日期、材料发布日期、发言人、原话所在页或时间戳、覆盖期间；区分公司指引、愿景、研究者推断和提问者观点。非官方转述需核实或降级。
- 建立短表：“管理层说法 → 可观察指标 → 现有支持/冲突 → 预测如何处理 → 何时验证”。只记录影响结论的事项。
- 用可取得的历史指引与后来结果核对，解释行业冲击、口径变化和选择性披露，不只摘录兑现案例。用当时可得信息评价历史判断，避免事后信息倒灌。
- 与报表冲突时，不把管理层解释直接覆盖已披露数字。给出可能的时点、口径或业务原因；无法解释则降低对应预测信心。
- 缺少公开沟通材料时注明检索范围和缺口，不猜测内容；仅当缺口影响关键假设时降低该假设的可用性。

## 输出与决策

正文给出影响最大的 1—3 项发现及含义；其余核对可放附录，没有重大异常也不必凑数量。关键调整表保留原值、调整额、依据和正常化结果。若调整量无法可靠估计，使用条件性范围或保留原值加压力情景，不捏造精确调整额。

关键收入真实性、资产可回收性或资金可得性无法判断时，估值标为条件性或暂缓；不能只加大安全边际就称问题已解决。银行、保险、券商重点核查资产质量、信用/准备金估计、投资估值、监管资本与普通股归属，不能机械套用工业企业现金指标。
