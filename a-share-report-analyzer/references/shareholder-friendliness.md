# 股东友好度与资本配置

围绕普通股股东能否获得经营成果分析，参考 Good Stocks Cheap 第13章，不能只数分红和回购次数。

| 检查 | 证据与判断 |
| --- | --- |
| 薪酬及持股 | 薪酬、奖励条件、真实自有资金持股、激励费用及稀释；低价授予不等于主动增持 |
| 关联交易 | 对手方、金额、定价、审批和回款；查控股股东占用、担保与利益输送，不因存在关联交易就否决 |
| 再投资与并购 | 投入金额、回报、兑现与商誉减值；历史ROE高不能证明新项目回报高 |
| 增发与稀释 | A/H发行、可转债、激励、其他权益工具；对普通股每股价值的净影响 |
| 回购 | 实际执行额、价格、用途、注销与重新发行；计划不等于执行；回购抵消激励不自动创造价值 |
| 分红 | 已实施/拟议、所属财年、总额、现金或监管资本覆盖、可持续性；高股息不自动说明安全 |

金融业单列留存资本、风险加权资产增长、监管资本缓冲以及普通股分红承受能力。

给通过/不通过/证据不足与依据。严重且已证实的治理问题不能用竞争力、增长或廉价抵消；缺乏完整核验不能把“未发现问题”写成无条件清白。
