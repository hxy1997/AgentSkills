# Workflow Overview

顺序为数据与理解 → 企业质量 → 估值与验证。价格可提前采集，质量判断不以便宜为理由放宽。

1. 明确研究时点、股份类别、策略类型和业务理解句。
   持仓复核/组合初筛另按 `holding-portfolio-modes.md` 缩放范围，初筛不强制逐股全报告。
2. 读取官方财务与附注，统一期间、币种、合并范围、普通股口径。
3. 完成子行业叠加及同行比较；可用子代理时委派行业研究。
   同时核查 `evidence-packages.md` 与 `valuation-anchor-framework.md`；重大商品/海外敞口按 `macro-policy-transmission.md` 建立传导及敏感性。
4. 检查资本回报、每股增长、现金/可分配资本、竞争和股东友好度。
5. 底线判断使用通过、不通过、证据不足。通过只代表现有证据未发现足以否决的障碍。
6. 条件允许则做独立估值情景、交叉验证及安全边际；否则明确暂缓原因。
   应用 `market-liquidity-expectations.md`，检查价格隐含条件与预期差；共用宏观假设调整记录，避免重复计价。
7. 写反证和复核条件，按报告模板交付并检查证据与计算。

阈值要有经济或监管依据，作者个人偏好的阈值不能冒充普适标准。
